# Countersign web app

React 19, TypeScript, Vite, Tailwind v4, TanStack Query, React Router, Motion.

```bash
npm install
npm run dev        # http://localhost:5173 (proxies /api to http://localhost:8000)
npm run gen:api    # regenerate src/api/schema.d.ts from ../openapi.yaml
npm test           # Vitest
npm run build
```

Design tokens and screen specifications: `../claude-code/PROTOTYPE.md`.
